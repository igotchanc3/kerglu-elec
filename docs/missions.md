## Dépendances avec les autres corps d'état
- **Doublage** (critique) : poser l'apparent sur ossature avant fermeture.
- **Plomberie** : croisements eau/élec, position prise lave-linge selon arrivée d'eau.
- **Isolation** : réserver un fourreau pour la traversée de mur du R2V.
- **Tranchée** : coordonner avec réseaux d'eau/évacuations enterrés.

## Méthode de chantier
- Polar fait tous les raccordements et terminaisons ; les bénévoles posent sur repères avec consignes claires.
- Viser la solution la plus simple compatible avec la sécurité.
- Approvisionnement : composants DC/solaires chez spécialistes (La Boutique Solaire, Solaris…) ; modulaire AC chez distributeurs (123elec, materielelectrique.com, elec44) ; consommables en GSB ; récup en recyclerie.
